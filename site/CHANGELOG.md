# 更新日志（历史存档）

> 客户端只读 `version.json` 里**当前版本**的 `changelog`（安卓看顶层，PC 看 `pc.changelog`）。
> 这个文件只用于人查阅，不会被 App 或官网脚本读取。

## Android 1.6.5

- 新标签页版式改回「上方 logo、中间搜索框、下方六个宫格」—— 电脑与手机一致
- 新标签页那六个宫格不再能被删掉，顺序也不随任何操作变化（以前点掉一个，剩下的会往前挪位）
- 新标签页中间新增搜索框：回车或点「搜索」即按你设置的搜索引擎打开
- 左上角 logo 现在点一下就能进设置
- 自动更新重做了：修好「检查更新必然失败」；发现新版会自动下载，下载完自动拉起安装器（有 8 秒倒计时可喊停，也可在「关于」里关掉）
- 扩展现在可以单独启用/停用；扩展面板改成先看已装的，「移除」明确标注不可撤销
- 修复装完扩展后开启浏览器特别慢（每次启动都在重新解包全部扩展）
- Edge 应用商店的取包接口已被微软关闭，新增「从已安装的浏览器导入扩展」作为替代；也可以直接粘 .crx / .zip 下载地址安装
- 修复扩展安装的多处问题：拖入无反应、选中装着安装包的文件夹报错、扩展包外层多包了一层时报错
- 修复「从已安装的浏览器导入书签」与导出后再导入会丢条目；修复网页里下载不显示进度

## PC 1.0.16 – 1.0.23 期间累计的条目

- 修复自动更新与网页下载的进度条不跟着百分比走（在「关于」页里一直卡在 0%）
- 拼图图标改为独立的「扩展」小窗：一行一个扩展，开关即可就地启用/停用，底部可直接「从文件安装」
- 拼图小窗里的扩展开关不再因布局被挤成圆形
- 修好「装上/开启的扩展看着没生效」：切换扩展开关后会立刻重载受影响的标签页，让扩展对正在看的页面也马上起作用（扩展只作用于 Chromium 内核的页，其它内核的页不会白重载）
- 侧边栏/弹窗型扩展（豆包/Cici、DeepSider 等）现在能打开界面了：Electron 不渲染扩展侧边栏与动作弹窗，Nova 自己加了停靠面板，用网页视图打开扩展自己的 side_panel.html / popup.html / options.html
- 扩展小窗新增「从浏览器导入」：就地扫描本机已安装浏览器里的扩展并一键导入，不必再专门跳进设置页
- 修好侧边栏扩展「单独弹出窗口、不嵌入面板、加载特慢」：承载面板现在会拦截扩展的 window.open——扩展自己的页面载回面板内、外部链接开成普通标签页，不再弹出独立小窗（也顺带少了重复加载）；面板载入时顶部有加载提示
- 修好侧边栏扩展点开后空白：承载面板不再把扩展 window.open 的地址导航进面板（那会变空白）——扩展自己的页面保留在面板里就地渲染，外部登录页开成标签页，登录后侧边栏可就地刷新
- 顶栏（品牌名右侧）新增「关于」按钮，一键进关于/版本/更新；「主题」「收藏夹」按钮补上文字
- 工具栏动作按钮（下载 / 广告拦截 / 媒体嗅探 / 扩展 / AI / 更新 / 菜单）加上文字标签，地址栏自动让出宽度
- AI 助手新增「API」模式：内嵌网页常被对方识别成「环境异常」拒绝渲染，现可选 API（默认 DeepSeek，兼容其它 OpenAI 风格接口），填 地址 / Key / 模型 即可对话；请求由本机直发，Key 只存本机设置
- 点地址栏里的网址弹出分享面板：复制链接、复制简介（标题+简介+链接）、生成二维码（本地生成，不把网址发给第三方）、分享到微博（网页分享）；微信 / 朋友圈 / 小红书 桌面无接口，用本地二维码扫码或复制标题+链接桥接
- 修好网页打不开时界面一片空白：加载失败现在显示「无法打开此网页」提示页（含具体原因 + 重试 / 回到首页），而不是什么都不显示
- 地址栏自动匹配：打字时从收藏夹和历史记录里补齐网址（收藏优先、按网址去重），下拉里 ↑↓ 选择、回车进入，点一行直接跳转
- 新增「密码 / 登录凭证」（设置 → 密码）：Nova 自己保存账号密码（系统加密、只存本机、不上传），可「填充到当前页」自动填入登录框，支持手动添加/显示/复制/删除。另提供「从 Edge 导入」——但新版 Edge 用 App-Bound 加密（v20），第三方无法解密，会如实跳过
- 网页右键菜单：链接（新标签页打开 / 复制链接）、选中文字（复制 / 搜索）、输入框（剪切 / 粘贴 / 全选）、后退 / 前进 / 刷新
- 选中文字后弹出迷你条：搜索 / 复制（搜索在新标签页打开）
- 更新小窗改版：不再是整屏侧栏，改成贴着更新按钮的自适应小窗——高度随更新日志伸缩（内容多才滚动），进度条下不再留一大片空白；更新日志在「下载中 / 已下载」时也一并显示
- AI 面板改版：不再是整屏右侧栏，改成贴在工具栏 AI 按钮下方的紧凑小窗（约 400×520，内容多才滚动）
- 针对 AI 站点「使用环境异常」风控：网页模式加了隐身预处理（抹平 webdriver / plugins / userAgentData 等内嵌浏览器特征）；仍被拦时面板会提示改用「API 模式」（用自己的 Key，不经过对方网页风控）

## PC 1.0.23

- IE 模式改为真·IE11 渲染：内置原生 Trident 宿主，基于 IE 的 ActiveX / VBScript / 条件注释系统现在可以正常打开了
- IE 页面支持鼠标点击、键盘输入与滚轮滚动，地址与标题会实时同步
- 原生宿主随安装包一起分发，不需要另外安装任何组件
- 设置 → 内核桥接 会如实显示 IE/Trident 当前是「原生桥接」还是「兼容层」
