不内置内核的浏览器，
把安装包与内存都省下来

吾爱Nova 是一款同时提供 Windows 桌面版与 Android 手机版的开源浏览器。 手机版不内置内核，渲染交由系统 WebView（Chromium）完成，安装包约 800 KB； 桌面版内置 Chromium 156（Electron 45）真内核，另有原生宿主 / 兼容层运行时可切换。 多线程下载、广告拦截、用户脚本、 无图模式与自动拼页两端均已具备；做不到的部分，在下方逐条写明。

核心能力，逐项可验证

每一项能力都对应一段可直接翻阅的实现，测试与代码同步。官网只呈现经过验证的功能，不写做不到的事。

双端多线程下载引擎

基于 Range 分片并行下载，支持断点续传与分片校验。服务器不支持分片时如实退回单线程，实际生效的线程数可在下载详情中查看。

双端广告拦截

网络规则与元素隐藏两级拦截，内置三源规则，支持订阅源自动更新，无需手动维护最新规则。

双端第三方脚本拦截

严格隐私模式：拦下一切非同源的脚本、跟踪像素与第三方资源，默认不把你的浏览行为共享给任何第三方。

双端划词搜索 + 翻译

页面里选中文字即可一键搜索或打开有道翻译（国内可用、免密钥），当前页不丢。

双端网页安全面板

一眼看清当前页的资源构成、SSL 证书状态与本次会话的拦截统计，技术细节不藏私。

双端用户脚本

按网址规则注入用户脚本，行为与 Tampermonkey 类扩展同源；可一键停用。内置「网页限制解除」等口碑脚本，开箱即用。

双端推荐脚本库

按公开装机量精选的脚本清单随包内置，点哪条装哪条；许可允许的那些正文也随包发，断网照样装。装前自动检测脚本能力并如实列出，避免装了跑不起来。

双端无图模式 + 自动拼页

三档控图，验证码与关键缩略图智能放行不误伤；列表页自动拼接下一页，兼顾省流与连续阅读。

双端多标签 · 本地历史

标签总览、切换后还原滚动位置；浏览记录仅存本机，无痕模式下不写入任何记录。

双端应用内自动更新

新版本后台静默下载，界面仅提示「重启更新」。下载包带 sha256 校验，官网直链与 Gitee Releases 双源互为兜底。

PC拖入即装扩展

把下载好的 .crx / .zip / .xpi 直接拖进浏览器窗口即自动安装，不必再翻菜单选文件。火狐扩展会先做清单归一化与 browser.* → chrome.* 桥接，并如实列出做了哪些兼容改动。

PC地址栏旁的下载浮窗

开始下载即在地址栏旁自动弹出，就地看到进度、速度与剩余时间，可暂停、继续或直接打开文件夹。 不想被打扰时手动收起，之后的下载也不会再自动弹出。

PCAI 助手侧边窗口

页面右侧滑出 AI 面板：写好内容、右侧下拉选 AI，结果就在面板里看。 内置 DeepSeek / Kimi / 通义千问 / 豆包，也可自定义地址； 「带入当前页」能把选中文字带进输入框。

PC双档内核可切换

内置 Chromium 156（Electron 45）真内核，地址栏右端还可切到 IE(Trident) 运行时，兼容层如实标注。 新标签页自带常用入口与插件商店入口，扩展与收藏夹开箱可用。

标 双端 的能力两端均已具备；标 PC 的为电脑版独有。手机版独有的能力见下方「只有手机版有」一节。

最近更新

每次发布写明改动与原因，修复的缺陷也照实列出。

电脑版 3.0.0 2026-11-11
  • 新增官网插件商店：设置 → 扩展里直接浏览官方精选插件，点「安装」即可，不用再自己找 .crx 拖进来。首批收录篡改猴、uBlock Origin、Dark Reader。
  • 目录只有一个源：官网、Gitee、GitHub 三处自动回退，任一处挂掉仍能拉到列表；官网「插件商店」板块和浏览器内商店读的是同一份清单，不会各说各话。
  • 安装链路复用既有能力：已安装判重、下载失败、地址不合法都有明确反馈；清单字段做了白名单与兜底，目录写错也不会把浏览器带跑偏。
  • 能力边界照实写明：官网目前只托管目录，扩展包本体仍取自 Chrome 应用店国内镜像。清单已预留自托管字段，以后把包放进官网或对象存储，改一个字段即可切换。
手机版 2.0.0 2026-11-11
  • 修复：每次打开网页都自动进入地址栏编辑态。根因是初始焦点落在地址栏输入框上，一进页面就弹键盘；现在由顶栏容器接管初始焦点。
  • 三处兜底收起：导航前、页面重建后、顶栏由隐藏切回显示时都会主动清焦点、收联想与浮层；扫码返回、新标签页、书签历史切换也不会误触发。
  • 清单声明 stateHidden，软键盘启动行为与页面加载解耦；延后的清理任务可被「主动聚焦地址栏」取消，不会跟你抢焦点。
电脑版 2.0.7 2026-11-09
  • 修复：保存的账号密码不自动填入。旧写法直接改输入框的值，React / Vue 这类受控表单会判定「值没变」，下一次渲染又把它清空。现在改用框架能感知的写入方式，并派发真实的输入事件。
  • 认得出多种登录页：注册框、蜜罐框、「显示密码」切换框并存时，只挑带 current-password 语义的那一组；页面异步重绘、异步出现的表单也能接住。
  • 保存与填充统一站点口径：都按网页真实地址核对，登录后重定向不再失配；跨站 iframe 仍取不到别站的记录。
  • 新增「GitHub 加速」：设置里可选整站镜像与 raw / Release / 源码包镜像，附「检测哪个节点能用」并发实测并自动选最快可用节点。默认关闭；登录页、api.github.com、非 GET 请求一律直连官方。
  • 能力边界照实写明：浏览器没有出口节点，无法给任意 Cloudflare 站点提速，也绕不过 5 秒盾 / Turnstile。镜像服务自身用 CF 分发，与「给 CF 站点加速」不是一回事。
  • 顶栏 AI 图标换成品牌渐变彩色，与手机版造型统一；深浅主题自动切换端点色。
手机版 1.7.5 2026-11-09
  • 页面缩放即时生效：设置里切 90 / 100 / 125 / 150% 当前页立刻变大变小，不用刷新；切回 100% 能准确复原。旧版只在下一次加载文档时起作用，选完档位屏幕一动不动。
  • 双指缩放不再被网页禁掉：站点写了 user-scalable=no / maximum-scale=1 也能捏合；注入只放开缩放属性，保留网页原有的宽度与排版。
  • 新标签页内嵌 AI 提问框：输入问题回车即带着问题打开 AI 对话，问题自动填进输入框。
  • 扫一扫移进搜索框：「转到」左侧一点即起相机；撤掉原来浮在右上角的两个小按钮。
  • 修正新标签页资源同步：上一版部分安装包里的 AI 提问框与扫码键可能缺失，这一版已补齐。

只有手机版有的能力

下列功能依赖触屏交互与系统能力，在电脑版上没有对应物。

Android上划唤出搜索框

在底栏区域向上滑动即唤出胶囊搜索框，地址栏与标签栏同时收起，网页净增一屏高度。任何页面都可触发——包括新标签页这类本身不滚动的页面。

Android星形收藏与收藏夹

地址栏右侧星形按钮一键收藏。收藏夹面板逐条列出，每条显示标题与网址，可点开也可单条删除；支持导出为 JSON，并可直接导入 Chrome / Edge 导出的 HTML。

Android底栏工具箱

下载、阅读模式、翻译、观影、篡改猴、广告拦截、网页安全与收藏夹集中于一格之内；面板右上角直达设置，下拉或轻扫即可关闭。

AndroidAI 助手

顶栏右端常驻入口，内嵌对话窗口，支持下拉切换服务商（DeepSeek / Kimi / 通义千问 / 豆包）与输入框直问。

两端对照

两端共享同一套核心能力（拦截、下载、脚本、无图），但在扩展生态与交互形态上各有侧重。以下按端列出实际差异，便于判断哪一端更符合你的使用方式。

Windows 电脑版 · v3.0.0 约 102 MB
  • 扩展拖入 .crx 即自动安装
  • 渲染Chromium 156 真内核 / 原生宿主 / 兼容层 三档可选
  • AI侧边窗口，内嵌对话，不打断当前页
  • 下载地址栏旁浮窗，整体进度条 + 分片细节
  • 收藏可停靠到视口右侧竖排；支持从 Chrome / Edge 直接导入
  • 内核版本Chromium 156（Electron 45），跟随应用自动更新
  • 触屏手势不适用（桌面端无此形态）
Android 手机版 · v2.0.0 约 800 KB
  • 渲染交由系统 WebView（Chromium），零个 .so
  • 上划底栏上划唤出搜索框，任意页面可触发
  • 收藏星形一键收藏，面板可导入导出
  • 工具底栏工具箱集中八项入口
  • 内核更新跟随系统，无法独立升级
  • 浏览器扩展不提供；用户脚本与篡改猴独立管理

在浏览器里装

PC 版打开 设置 → 扩展 → 官网插件商店，在卡片上点「安装」： 浏览器自己取包、解包、装载，装完出现在「已安装」里，可随时开关或移除。

网页为什么不能直接装

网页没有操作本地扩展的权限，第三方外壳也不是 Chrome 应用店， 商店页上的「获取」按钮点了不会有反应。所以官网只做目录与入口， 安装动作一律由浏览器自己完成。

包的来源如实标注

下面几款走 Chrome 应用店国内镜像（Google 官方域名在国内连不上），卡片上标了来源。 官网目前不托管扩展包本体，只维护目录；以后若改为自托管， 清单会改用 download/ext/ 下的直链。

已知限制与技术取舍

下列各项均标注了实际代价与适用边界。请在使用前确认它们是否符合你的需求——我们认为如实说明局限，比罗列功能更有价值。

取舍内核策略：手机不内置，桌面内置

Android 版安装包约 800 KB，是因为 APK 中零个 .so——渲染交由系统 WebView（Chromium）完成。 换来的是极小的体积与更低的内存占用；代价是内核版本跟随系统，无法独立升级。 桌面版则内置了一份 Chromium 156（Electron 45）真内核，所以体积较大（约 102 MB）； Trident 由可选的独立宿主进程承载，未安装时自动降级为兼容层。 我们认为对多数用户这是值得的取舍，但你应当了解这笔账。

如实桌面端三档运行时的标注

桌面版提供三档渲染路径，由用户在设置中自行选择：原生内核（进程内渲染）、 原生宿主（由独立宿主进程渲染 Trident），以及兼容层 （用 Chromium 渲染，但完整伪造目标内核的 UA、文档模式与 API 垫片）。 兼容层不等于真内核——原生宿主二进制不存在时会自动降级为兼容层， 界面如实标注当前实际生效的那一档。扩展方面支持拖入 .crx 自动安装。

如实无图模式的边界

移动端无图按资源后缀判断，覆盖常见图片格式，但并非万无一失—— 验证码与关键内容走放行名单，其余边界在源码注释中逐条注明。设置中的每个开关均真实生效。

取舍下载并行视服务器而定

多线程下载依赖服务器支持 Range 分片。探测到不支持时自动退回单线程并正常完成下载， 不会伪装并行——实际生效的线程数可在下载详情中查看。
