FEATURES

该有的都有，说出去的都做到

每一项能力都对应一段可以直接翻阅的实现，测试跟着代码走——官网里不写做不到的事。

⇩

多线程下载引擎

Range 分片并行、断点续传、分片校验。服务器不支持分片时如实退回单线程，设置里选几线程就显示几线程。

🛡

广告拦截

网络规则 + 元素隐藏两级拦截，内置三源规则，支持订阅自动更新——不用手动去找最新规则。

⚙

篡改猴用户脚本

按网址规则注入用户脚本，行为与 Tampermonkey 一类扩展同源；装错了也可以一键停用。

◐

无图模式 + 自动拼页

三档控图，验证码与关键缩略图智能放行不误伤；列表页自动拼接下一页，省流量也省翻页。

▣

多标签 · 本地历史

标签总览、切换后还原滚动位置；浏览记录只存本机，无痕模式下一条都不写盘。

↑

应用内自动更新

有新版不用先点「下载」：直接在后台下好，界面上只留一句「重启更新」。下载包带 sha256 校验，官网与 Gitee Releases 双源互为兜底。

HONESTY

先把「我们没什么」说清楚

这一节比功能列表更重要。选择都有代价，写出来是让你带着判断来用，而不是被宣传语请进来。

取舍为什么不内置内核

安装包只有三百多 KB，因为 APK 里零个 .so——渲染交给系统 WebView（Chromium）。 换来的是极小的体积和更省的内存；代价是内核版本跟随系统，无法独自升级。 我们认为对大多数用户这是笔划算的买卖，但你应当知道这笔账。

如实桌面端三档运行时的标注

桌面版提供 Chromium / Gecko / IE(Trident) 三档，只有 Chromium 是真内核， 另两档是如实标注的兼容层——界面上就这么写，不做假选择。支持安装 .crx 与 .xpi 扩展。

如实无图模式有盲区

移动端无图按文件后缀判断，覆盖常见图片格式，但不是万无一失—— 验证码与关键内容走放行名单，其余边界在源码注释里逐条写明。设置里的每个开关都真的生效。

取舍下载并行视服务器而定

多线程下载依赖服务器支持 Range 分片。探测到不支持时自动退回单线程并照常下载， 不会假装并行——你可以从下载详情里看到实际生效的线程数。
